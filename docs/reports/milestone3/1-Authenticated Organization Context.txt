## 1. Objective
Implement a secure organization context mechanism that identifies the authenticated user and validates their membership before allowing access to organization-specific resources.

## 2. Implementation Completed

**New Components:**
- `AuthenticatedOrganizationContext.java` — Immutable record containing user ID, organization ID, membership ID, and membership role.
- `AuthenticatedOrganizationContextResolver.java` — Resolves organization context using the authenticated JWT identity and validates membership, user, and organization status.

**Updated Components:**
- `OrganizationService.java` — Integrated organization context validation before permission checks and database access.
- `OrganizationServiceTest.java` — Added resolver dependency and security verification tests.

**Security Measures:**
- Rejects users without valid organization membership.
- Rejects suspended memberships, users, and organizations.
- Prevents organization data retrieval when context validation fails.
- Preserves existing role-based authorization.
- Enforces the execution order: context validation → permission verification → data retrieval.
