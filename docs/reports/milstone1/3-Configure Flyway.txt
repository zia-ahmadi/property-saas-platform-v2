5. Important architectural decisions
1. Flyway owns database schema changes. Hibernate uses ddl-auto=validate, not automatic schema creation.
2. Migration history is version-controlled. Future structural changes should use new migration files such as V2__...sql, V3__...sql.
3. Multi-tenancy foundation is established. Users can belong to multiple organizations through organization_memberships.
4. Initial scope remains deliberately small. Property, lease, maintenance, billing, and other business tables will be introduced in later migrations.
