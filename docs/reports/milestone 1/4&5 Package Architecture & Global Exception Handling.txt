2. Global Exception Handling

Status: Implementation complete

Implemented centralized exception handling in:

common/exception/GlobalExceptionHandler.java

Components

ErrorResponse.java

Implemented as a Java record containing:

timestamp — time of the error.

status — HTTP status code.

error — HTTP status description.

message — safe message for API clients.

path — requested endpoint.

GlobalExceptionHandler.java

Implemented using Spring's @RestControllerAdvice and @ExceptionHandler(Exception.class).

Current behavior

Intercepts unexpected exceptions.

Logs the request URI and exception stack trace using SLF4J.

Returns HTTP 500 Internal Server Error.

Provides a standardized ErrorResponse.

Hides internal exception details from API clients.

Security consideration

The API returns a generic error message rather than exposing stack traces, database details, or internal implementation information.

Current limitation

The handler currently provides a general HTTP 500 response. Specific exceptions, such as validation failures and missing resources, will need dedicated handlers to return appropriate HTTP 4xx responses.
